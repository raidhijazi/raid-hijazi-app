# حكايا رائد حجازي

تطبيق ويب لكتب الكاتب رائد عبدالرحمن حجازي، مع معجم المفردات التراثية، ومثل اليوم، والتسجيلات الصوتية، والفيديوهات.

- `index.html` — التطبيق الجاهز للنشر (يُولَّد آلياً، لا يُعدَّل يدوياً).
- `src/app.html` — مصدر التطبيق.
- `data/` — نصوص الكتب والمعجم والأمثال.
- `build.py` — يبني `index.html`:  `python3 build.py`
- `sw.js` — عامل الخدمة: فتح التطبيق دون اتصال، مع جلب آخر نسخة من الصفحة الرئيسية كلما توفّر الاتصال.
- `privacy.html` — سياسة الخصوصية بالعربية والإنجليزية (رابطها مطلوب في Google Play).
- `supabase/setup.sql` — إعداد قاعدة البيانات ومخزن الملفات.

المحتوى الذي يضيفه المحرّر (المعاني، الأمثال، التسجيلات، الفيديوهات) يُحفظ في Supabase، ويظهر للجميع فوراً.
